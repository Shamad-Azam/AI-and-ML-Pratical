# AI and ML Practical – Prolog

This repository contains Prolog practical programs completed as part of the Artificial Intelligence and Machine Learning (AI & ML) practical coursework.

## 📚 List of Practicals

1. Student Course Knowledge Base
2. Arithmetic, Factorial and Fibonacci
3. List Operations
4. College Timetable
5. Student Performance
6. Breadth-First Search (BFS)
7. Greedy Best-First Search
8. A* Search Algorithm
9. Hill Climbing
10. Simulated Annealing
11. Map Coloring using CSP
12. N-Queens using CSP

## 🛠️ Technologies Used

- Prolog
- Artificial Intelligence
- Search Algorithms
- Constraint Satisfaction Problems (CSP)

## 🎯 Objective

The objective of these practicals is to understand the fundamentals of Prolog programming and implement various Artificial Intelligence techniques, search algorithms, and constraint satisfaction problems.
